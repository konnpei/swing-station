# チェック管理アプリ（swing-stationとは無関係の別プロジェクト）

このフォルダは、SWING STATION（株スイングトレード情報サイト）とは**無関係の別アプリ**です。
GitHubの新規リポジトリ作成権限が一時的に使えなかったため、暫定的にこのリポジトリ内で管理しています。
将来的に権限が使えるようになった場合は、専用リポジトリへ分離することを推奨します。

## 概要

飲食店・食品工場向けの衛生管理チェックアプリをベースに、同一エンジンで用途別にデプロイした
チェックリストPWA。素のHTML/CSS/JS + IndexedDB（端末内保存）+ Service Worker（オフライン対応）。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `swing-trade-app/` | スイングトレード用チェックアプリ（デフォルト配色: さわやか） |
| `study-quiz-app/` | 子供向け まいにち小テスト（漢字・算数、学年別、選択式） |
| `hygiene-app/` | お店用・家庭用 衛生管理チェックアプリ ※未追加 |

各アプリは独立したIndexedDB(端末内保存)を持つ。担当者ごとの配色・ポイント制・
記録カレンダー・データのエクスポート/インポートなど、共通で使える仕組みは
アプリごとにコピーして流用している（サーバーがないため直接の共有はできない）。
設定画面から他アプリへのリンクを置いている。

## デプロイ方法

`main`ブランチへのpush時に`.github/workflows/deploy-check-app-pages.yml`が
自動実行され、GitHub Pages（`https://konnpei.github.io/swing-station/`配下）に
公開される。
