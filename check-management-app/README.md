# チェック管理アプリ（swing-stationとは無関係の別プロジェクト）

このフォルダは、SWING STATION（株スイングトレード情報サイト）とは**無関係の別アプリ**です。
GitHubの新規リポジトリ作成権限が一時的に使えなかったため、暫定的にこのリポジトリ内で管理しています。
将来的に権限が使えるようになった場合は、専用リポジトリへ分離することを推奨します。

## 概要

飲食店・食品工場向けの衛生管理チェックアプリをベースに、同一エンジンで用途別にデプロイした
チェックリストPWA。素のHTML/CSS/JS + IndexedDB（端末内保存）+ Service Worker（オフライン対応）。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `swing-trade-app/` | スイングトレード用チェックアプリ（デフォルト配色: ゴールド） |
| `hygiene-app/` | お店用・家庭用 衛生管理チェックアプリ（デフォルト配色: オーシャン）※未追加 |

## デプロイ方法

対象フォルダの3ファイル（`index.html`, `manifest.json`, `sw.js`）を
https://app.netlify.com/drop にドラッグ&ドロップ。
